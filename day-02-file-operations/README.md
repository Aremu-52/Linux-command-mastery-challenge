# Day 2 — Creating, Copying, Moving & Deleting

## Overview

Day 2 of the 30-Day Linux Command Mastery Challenge focused on creating, copying, moving, renaming, and deleting files and directories in Linux.

The goal was to become comfortable managing files and directories from the terminal using common Linux commands.

## Commands Practiced

- `mkdir` — creates a directory.
- `mkdir -p` — creates nested directories, including parent directories when needed.
- `touch` — creates an empty file or updates a file's timestamp.
- `cp` — copies a file.
- `cp -r` — copies a directory and its contents recursively.
- `mv` — moves or renames a file or directory.
- `rm` — removes a file.
- `rm -r` — removes a directory and its contents recursively.
- `rm -rf` — forcefully removes a directory and its contents recursively.
- `rmdir` — removes an empty directory.

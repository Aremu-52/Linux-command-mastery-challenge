# Day 2 — Linux Commands

## 1. mkdir

Creates a new directory.

Example:

`mkdir projects`

---

## 2. mkdir -p

Creates a directory and any required parent directories.

Example:

`mkdir -p practice/2026/april`

---

## 3. touch

Creates an empty file.

Example:

`touch file1.txt`

---

## 4. cp

Copies a file from one location to another.

Example:

`cp file1.txt backup.txt`

---

## 5. cp -r

Copies a directory and everything inside it.

Example:

`cp -r practice backup`

---

## 6. mv

Moves or renames a file or directory.

Example:

`mv file1.txt renamed-file.txt`

---

## 7. rm

Removes a file.

Example:

`rm file1.txt`

---

## 8. rm -r

Removes a directory and its contents recursively.

Example:

`rm -r old-folder`

---

## 9. rm -rf

Forcefully removes a directory and its contents recursively.

Example:

`rm -rf old-folder`

Use this command with caution because it can permanently remove files and directories without asking for confirmation.

---

## 10. rmdir

Removes an empty directory.

Example:

`rmdir empty-folder`

---

## Key Lesson

The main difference I learned is that Linux uses different options depending on whether I am working with a file, an empty directory, or a directory containing other files and directories.

# Day 2 — Practice Drill

## Objective

Practice creating, copying, moving, renaming, and deleting files and directories using Linux commands.

## Steps Completed

### 1. Create the nested directory structure

Created:

`practice/2026/april`

using `mkdir -p` in one command.

### 2. Create three empty files

Created the following files inside the `april` directory:

- `file1.txt`
- `file2.txt`
- `file3.txt`

using `touch`.

### 3. Copy the folder

Copied the `practice` directory to a backup location using `cp -r`.

### 4. Rename a file

Renamed one of the files using `mv`.

### 5. Remove empty directories

Safely removed only the empty directories left behind using `rmdir`.

## What I Learned

This drill helped me understand how Linux commands can be combined to manage a directory structure. I also learned that `rmdir` only works on empty directories, while recursive removal commands are needed when directories contain files or other directories.

# Day 1: Where Am I? Basic Orientation

## Phase 1 - File Navigation & Filesystem Mastery

## Commands Covered

Today I practiced the 10 required Linux navigation commands:

- `pwd`
- `ls`
- `ls -l`
- `ls -a`
- `ls -la`
- `ls -lh`
- `cd` (absolute path)
- `cd ..`
- `cd ~`
- `cd -`

## What I Practiced

I practiced checking my current working directory, listing files and directories using different options, navigating to `/var/log` using an absolute path, returning to my home directory using `~`, and returning to the previous directory using `cd -`.

I also practiced listing the contents of `/var/log` using long and human-readable format.

## What Surprised Me

I learned that `cd -` returns me to the previous directory, while `cd ..` moves me to the parent directory.
